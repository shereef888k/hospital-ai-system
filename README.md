# Hospital AI System (Triage)

## Overview
This project is an AI-powered hospital triage system that predicts patient urgency levels (Emergency, Medium, Low) and suggests the appropriate department. It helps improve decision-making and reduces manual workload in healthcare environments.

## Features
- Predicts patient urgency level
- Suggests hospital department
- Real-time input and response
- User-friendly interface
- AI-based decision support system

## Tech Stack
- Python (Backend)
- Flask (API)
- TypeScript / JavaScript (Frontend)
- HTML, CSS

## How it Works
1. User enters patient details (symptoms, duration, age)
2. System processes input using rule-based logic
3. AI classifies urgency level
4. Displays result and recommended department
